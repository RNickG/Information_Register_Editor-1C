Редактор регистров сведений

Основные функции

  • Редактирование как независимых, так и подчиненных регистратору РС
  • Пакетное изменение реквизитов записей РС по отбору (отбор как оп основным ключевым полям, так и произвольный отбор СКД)
  • Изменение регистратора записи для РС, подчиненных регистратору
  • Выполнение произвольного алгоритма при изменении записи РС
  • Выполнение обработки в режиме ОбменДанными.Загрузка = Истина
  • Возможность указания Дополнительных сведений набора записей РС при обработке
  • Отображение резульатата установелнного отбора в виде отчета
  • Возможность выгрзить в XML как все записи РС, так и записи по отбору (формат данных аналогичен используемому в типовой обработке Универсальный обмен XML)
  • Возможность загрузить данные РС из XML (формат данных аналогичен используемому в типовой обработке Универсальный обмен XML)
  • Отображение полей типа Хранилище значения
  • Возможность изменить значение в поле типа Хранилище значения (указать произвольное значение)
  • Возможность установить значение хранилища с использованием произвольного алгоритма
  • Возможность загрузить и выгрзуить двоичные данные для поля Хранилища значения
  • Возможность выггрузить из загрузить в XML значение в поле Хранилище значения
  • Отображение полей, содержащих строку с паролем
  • Отображение полей типа Уникальный идентификатор
  • Возможность изменения значения полей типа Уникальный идентификатор
  • Встроенный отчет по данным РС, с отображением значений в полях, содержащих пароли, возможность отображения в отчете УИД ссылочных данных.
