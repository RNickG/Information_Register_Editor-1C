# Редактор регистров сведений 1С
## Основные возможности
- Работа с как с независимыми Регистрами сведений, так и с подчиненными регитсратор
- Создание, изменение, удаление записей по произвольному отбору
- Изменение регистратора (перепривязка записей к другому регистратору)
- Выполнение произвольного алгоритма для полей записи при ее изменении
- Заполнение дополнительных свойств набора записей
- Работа с полями типа "Хранилище значения" (просмотр содержимого, редактирование содержимого)
- Работа с полями типа "Пароль" (просмотр, редактирование)
- Работа с полями типа "Уникальный идентификатор" (отбор по полю, редактирование, встроенный генератор УИД)
## Сервисные возможности
- Встроенный отчет по данным регистра
- Возможность резервного копирования в XML и загрузки из XML как части запсей так и всез записей регистра
## Примечания
- Работа только в управляемом приложении
